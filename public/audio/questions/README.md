# Audios de respuestas

Agregar los MP3 sin cambiar código usando esta convención:

`q01/option-1.mp3`, `q01/option-2.mp3`, `q01/option-3.mp3` … hasta `q24/option-3.mp3`.

Cuando estén disponibles, completar `audioSrc` y, opcionalmente, `duration` en `data/questions.ts`. La transcripción `text` es interna y no se renderiza en el test.
